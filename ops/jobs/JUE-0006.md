# JUE-0006 — Remove legacy scripts from ops/scripts

Goal: `ops/scripts/` holds only what the TypeScript `yarn` pipeline uses, so no agent runs an
outdated script by mistake. `ops/docs/commands.md` ("Legacy scripts in `ops/scripts/`") already marks
them do-not-use; this job confirms they are unused and deletes them.

## Pending
- For each candidate, confirm nothing references it (`grep` over `scripts/`, `package.json`,
  `Makefile`, Docker files, `.github/`, `ops/docs/`, excluding `node_modules`), then delete it:
  - `ops/scripts/transformWordsToJSON.sh`, `compareAndAdd.sh`, `extractFromText.sh`
  - `ops/scripts/raeCrawler/` (Python)
  - `ops/scripts/dictionaryApiCrawler/crawler.py`, `checker.py`
  - `ops/scripts/wordChecker/` (Go)
- Check each one has a `yarn` replacement listed in `commands.md`. If one has none, keep it and say
  so in the PR.
- Remove the "Legacy scripts" section from `ops/docs/commands.md` (and the `legacy` keyword from the
  `ops/docs/README.md` index) once they are gone.

## Notes
- **Keep** (live): `ops/scripts/words/`, `ops/scripts/frequency/`, `ops/scripts/copy_env.sh` (used by
  `make`), `ops/scripts/dictionaryApiCrawler/output.txt` (default output of `crawl:check-en`, in
  `scripts/crawlers/checkDictionary.ts`).
- Git history keeps the deleted files; no archive copy needed.

Done =
- the listed legacy files are deleted, or the PR names each kept one and why;
- `grep -rn` finds no reference to any deleted path;
- `yarn test` and `yarn lint` green; `git status` after `yarn words:transform` shows no diff in `public/words/`;
- `commands.md` no longer lists them.
