# JUE-0003 — Abeja deletreadora (spellingBee)

Nuevo juego `spellingBee`: se muestra una definición y el jugador escribe la palabra completa
desde cero en un input de texto libre (tildes incluidas). Se diferencia de definitionMaster
(opción múltiple → reconocimiento) exigiendo recuerdo ortográfico total. ES y EN.

- ES route `/juegos/abeja-deletreadora`, EN route `/en/games/spelling-bee`.
- Sesión de 5 definiciones (`TOTAL_ROUNDS = 5`), sin timer global; 3 intentos por palabra.
- Pistas progresivas (longitud + tipo gramatical → 1ª letra → última letra → palabra revelada).
- Puntuación 3/2/1/0 según intento; "accent-near-miss" da un reintento gratis de tildes por palabra.
