# JUE-0016 — Accessible feedback, shared results and mobile

Source: spike JUE-0008, proposed job 6; findings F12, F13, F15.

Goal: right and wrong are distinguishable without colour, results are announced, and the crossword is
playable at 375 px.

## Pending
- [ ] ✓/✗ icon or text in spellTower, letterMatcher, accentFixer, wordsRain and crossWordPuzzle.
- [ ] `aria-live="polite"` on score and result in every game.
- [ ] Move wordFinder's hard-coded `Letra` to the i18n catalogue.
- [ ] Labels on the crossword cells.
- [ ] Number the clues as well as colouring them, with AA contrast.
- [ ] Crossword grid that scales to 375 px.
- [ ] wordBuilder without overflow.
- [ ] A shared results component (verdict, list, «Play again») for the games that lack one.
- [ ] Error message in crossWordPuzzle when definitions fail to load.

## Notes
- No dependencies.
- Owner observed in live review (2026-11-09): in spellingBee the new hint after a wrong attempt (the
  first letter, then the last) is easy to miss; the message says «You get a new hint» but nothing
  points at the letter. Fits this job's feedback scope; confirm with the owner before adding it.

Done =
- UI tests (the first ones for accentFixer and letterMatcher) check a non-colour indicator and
  `aria-live`;
- UI tests for spellTower, wordsRain and crossWordPuzzle check that, after a hit and a miss, ✓/✗ shows
  (icon with accessible text, or text), not only a colour class;
- one UI test per game (10) checks that score or result sits inside an `aria-live="polite"` element;
- a crossWordPuzzle UI test checks that every editable cell has an `aria-label` with its clue number
  and letter position, and that every clue shows its number;
- crossword clue colours give contrast ≥ 4.5:1 (AA) with their text, checked by a test that computes
  the palette contrast or by axe in the browser;
- a wordFinder UI test rendered in en checks `aria-label="Letter 1"` on the first box;
- spellTower, wordsRain, wordFinder, definitionMaster and crossWordPuzzle use the shared component at
  the end, and one UI test per game checks verdict, list and play-again button;
- a crossWordPuzzle UI test with failed definitions shows the same error message as definitionMaster
  and spellingBee;
- a 375 px screenshot shows the whole grid without horizontal page scroll;
- at 375 px, the `mobile-es-m.json` script gives `wide: []` for wordBuilder (`word-builder-letters`
  right edge ≤ 375).
