# JUE-0010 — game descriptions and rules

Every game's texts live in `config/translations/Games.ts`, one `GamePreConfig` per game:
- `title`;
- `subtitle`;
- `description`;
- `gameRules` (`gameGoal`, `howToPlay[]`, `additionalRules[]`, `tips[]`), in es and en.

They are shown on the games list (`components/Games.tsx` cards, `HomeContent.tsx`), in the game
pages, and in the rules screen (`components/GameRules.tsx`).

Owner decision (2026-11-03): improve the descriptions so they **fit the space where they appear**, and
improve the rules. Some texts are long, and some are wrong. For example, `spellTower`'s `subtitle`
says "Es un juego competitivo donde los jugadores adivinan definiciones de palabras", which describes
another game: a copy-paste leftover.

## Pending
- [ ] **Measure the slots.** Build and serve the static site (`yarn build`, serve `out/`; kill the
  server after). Use the headless-browser skill at 375, 768 and 1280 px, es and en, and measure:
  - how many characters/lines each slot shows before it overflows, clamps or looks crowded: card
    title, card description/subtitle, game page header, and rules screen sections;
  - which current texts overflow, get cut, or push the layout.
  Turn the results into a **length budget per slot**, e.g. card description ≤ N characters / 2 lines
  at 375 px. Write the budget in `ops/docs/game-conventions.md`, so new games (JUE-0003, JUE-0005)
  follow it.
- [ ] **Rewrite per game**, for every game in `games/` plus the daily word, if it has texts.
  - **title:** short and stable. Change it only if it doesn't fit; list any title change in the PR.
  - **subtitle:** one line saying what the game is, and it must describe *this* game. Fix the
    copy-paste errors.
  - **description:** within the budget. What you do and what you practise (accents, syllables,
    spelling…), no filler.
  - **rules:**
    - `gameGoal`: one sentence.
    - `howToPlay`: short numbered steps that match the **real behaviour in code**. Read each game's
      hook (`games/<game>/use*.tsx`) and UI: scoring, lives/timer, levels, what counts as correct,
      what happens on a mistake and how the game ends.
    - `additionalRules`: the real special cases, e.g. JUE-0004 syllable rules or accent rules. None
      invented.
    - `tips`: useful, not generic.
  - es and en say the same thing; en is natural English, not a literal translation. Keep the
    existing keys and shape (`GamePreConfig`), no structural change.
- [ ] **Verify** with a second agent (content double-tap):
  - each rule is checked against the game's code;
  - each text is checked against its budget at all three widths.
  Take screenshots before and after for each game to `$JON_ASSETS_DIR/jue-0010/<game>/`.
